# NYC Taxi Operations Analysis

## Project Overview
This project analyzes NYC taxi trip data to understand trip patterns and daily taxi operations using Python.

## Objectives
- Clean the dataset and handle missing values.
- Identify outliers in trip distance, tip amount, and other fields.
- Analyze daily trip volumes and passenger trends.
- Explore payment details and taxi trip patterns.

## Tools & Technologies
- Python
- Pandas
- Jupyter Notebook / Google Colab
- Data Analysis and Visualization

## Key Findings
- Thursday recorded the highest number of trips among the days analyzed.
- Missing values and outliers were identified during data cleaning.
- Daily trip counts were compared to understand variations in taxi activity.

## Project File
- `NYC_Taxi_Operations.ipynb` — Notebook containing the data analysis and findings.

## Conclusion
This project helped me practice data cleaning, exploratory data analysis (EDA), and interpreting taxi trip data to identify useful operational insights.
